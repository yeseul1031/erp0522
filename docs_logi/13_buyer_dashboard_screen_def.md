# 13. 구매담당자 수급 터미널 화면정보 및 필드정의서

## 1. 화면 구성 아키텍처 (Screen IA)

### 1.1 Layout Zone
- **Top Header (GNB)**: 8개 주요 메뉴(Home, 공고 정보, 거래처 정보, 품목 정보, 입출고관리 등), **역할 전환 스위처** (김철수/이영희), **DEV GUIDE 토글** 및 프로필.
- **Left Sidebar (LNB)**: 뷰 토글(프로젝트/발주서), 검색창, **듀얼 진척도(입고/출고)**가 표시된 프로젝트/발주서 리스트.
- **Top Metrics**: 상단 고정 영역. 미입고 지연, 오늘 입고 예정, 이번 주 출고 예정 요약 카드.
- **Contextual Stats**: 목록 선택 시 나타나는 프로젝트/PO 전용 진척도(입고/출고 %) 카드.
- **Main Grid**: 수기 입력 전용 그리드. 프로젝트 뷰(13개 열)와 발주서 뷰(11개 열) 지원.

---

## 2. 주요 UI 필드 및 Data Constraints 정의

### 2.1 좌측 사이드바 (프로젝트 / 발주서 선택 LNB)
| 필드명 | 유형 | 속성 | 설명 및 제약조건 |
|---|---|---|---|
| **사이드바 토글** | Button | Action | `<` 또는 `>` 쉐브론 클릭 시 LNB 너비를 최소화하여 텍스트만 세로로 노출하는 슬림형 모드로 전환 |
| **뷰 토글(View Toggle)** | Segmented Control | Action | '프로젝트로 보기' / '발주서로 보기' 두 가지 모드 전환. 선택에 따라 목록 변경됨 |
| **통합 검색창** | Input | Editable | 현재 뷰 모드에 맞춰 프로젝트명을 실시간 필터링 지원 |
| **데이터 리스트** | List | Selectable | 뷰 모드에 따라 '활성 프로젝트' 또는 '발주서' 목록 노출 |
| **진행률/상태 뱃지** | Badge | Read-Only | (프로젝트) **입고(Blue) / 출고(Green)** 듀얼 진행률. (발주서) 입고 진행률(%)만 표기 |

### 2.2 메인 그리드 상단 컴포넌트 (요약 및 액션)
| 필드명 | 유형 | 속성 | 설명 및 제약조건 |
|---|---|---|---|
| **타이틀 영역** | Text | Read-Only | "입고 처리" 타이틀 및 화면 ID (SCR-INB-001) |
| **역할 전환 스위처** | Toggle | Action | 상단 중앙 배치. 김철수(오너)/이영희(담당자) 역할 전환. 선택 역할에 따라 편집 권한 실시간 변경 |
| **DEV GUIDE 토글** | Toggle | Action | 상단 중앙 배치. 가이드 메모 활성화 및 설명 툴팁(Sticky Memo) 노출 제어 |
| **거래처명 검색** | Input | Editable | 메인 영역 상단 배치. 전 프로젝트 대상 통합 거래처 검색 |
| **엑셀 다운로드** | Button | Action | SheetJS 연동. 현재 그리드 데이터를 엑셀로 추출 |
| **미입고 지연 품목** | Card | Read-Only | 납기일 도래 품목 중 입고 미완료 건수 |
| **오늘 입고 예정** | Card | Read-Only | 금일 입고 일자가 예정된 품목 수 |
| **이번 주 출고 예정** | Card | Read-Only | 현재 주차 내 출고 예정 건수 |
| **선택 건 진행률** | Card | Read-Only | (컨텍스츄얼) 선택 프로젝트의 입고/출고 % 상세 카드. **(PO 뷰에서는 출고 숨김)** |

### 2.3 메인 수급/입출고 입력 그리드 (계층형 데이터 컬럼)
| 필드명 (컬럼) | 위치 (계층) | 속성 | Constraints / 비고 |
|---|---|---|---|
| **NO.** | 공통 좌측 | Read-Only | 계층 인덱스 (Project-PO-Item) |
| **품목 정보 (ITEM / PO)** | Item 레벨 | Read-Only | 품목명 및 발주번호. 담당자별 마커(Blue/Purple) 표시 |
| **모델명/규격** | Item 레벨 | Read-Only | 사양 정보 |
| **거래처명** | PO 레벨 | Read-Only | 해당 발주서 거래처명 |
| **발주납품조건** | PO 레벨 | Read-Only | DDP, Ex-Works 등 |
| **내 물량** | Item 레벨 | Read-Only | 로그인 담당자 할당량 |
| **입고/전체** | Item 레벨 | **Inline Edit** | **Default**: 매입량 100%. **과입고 시 Indigo 하이라이트** 및 OVER 배지 |
| **입고예정일** | Item 레벨 | Read-Only | 예상 도착일 |
| **입고일자** | Item 레벨 | **Inline Edit** | 실제 입고일. PO 레벨 [일괄입력] 지원 |
| **출고실행** | Item 레벨 | **Inline Edit** | (Project View 전용) 현장 출고량. 입고량 한도 내 입력 |
| **출고일자** | Item 레벨 | **Inline Edit** | (Project View 전용) 실제 출고일 |
| **계약납기일** | Item 레벨 | Read-Only | 준수 기한 |
| **비고** | Item 레벨 | **Inline Edit** | 수기 메모 (최대 100자). 좁은 공간 말줄임표 처리 |

> **개발/UX 노출 규칙**: 상기 "입고수량 ~ 비고"까지의 인라인 수정(Inline Edit) 영역에서 포커스를 벗어나거나 값이 수정될 때마다 번거로운 수동 버튼 클릭 없이 [입력 내용이 자동 저장되었습니다] 토스트 메시지와 함께 `DB 실시간 트랜잭션`이 작동합니다.
