# 11. [사용자 가이드] 엑셀에서 NeoBH ERP 입출고 수기 터미널(SCR-PUR-001)로 업무 전환하기

구매 담당자 여러분, 그동안 복잡한 엑셀 파일과 수식으로 입출고 및 배송비를 추적하시느라 고생 많으셨습니다. 
새로 도입된 **입출고 수기 터미널 (SCR-PUR-001)**은 엑셀의 편리한 '직접 입력(Inline Edit)' 경험을 그대로 살리면서도, 데이터 손실과 수식 오류의 위험을 원천 차단한 시스템입니다.

다음에 안내된 **핵심 스텝 5가지**만 따라 하시면 엑셀보다 훨씬 쉽고 안전하게 업무를 전환하실 수 있습니다.

---

## Step 1. 엑셀 파일은 이제 그만! 브라우저 접속 바로가기
- **As-Is (기존)**: 매일 아침 공유 폴더에서 '2026_발주대장_V12.xlsx'를 열어 서로 편집 충돌이 나지 않게 관리해야 했습니다.
- **To-Be (변경)**: 시스템 메뉴의 **[구매/수급] > [입출고 수기 터미널]**에 접속하세요. 
모든 발주 진행 데이터가 엑셀 형태의 표(그리드)로 미리 그려져서 여러분을 기다리고 있습니다. 데이터 동기화나 파일 버전 관리는 잊어버리세요.

## Step 2. 넓은 화면 활용과 글로벌 거래처 검색
- **GNB 네비게이션**: 상단 GNB에는 '입출고관리'를 포함한 8개의 주요 메뉴가 배치되어 있어 다른 업무로의 전환이 빠릅니다.
- **역할 전환 스위처**: 상단 중앙에서 '구매오너: 김철수'와 '연관담당자: 이영희' 역할을 전환해 볼 수 있습니다. (담당자별 권한에 따라 편집 가능 영역이 자동으로 제어됩니다)
- **사이드바 최소화**: 화면 좌측에는 담당 프로젝트 목록이 보입니다. 상단의 `<` 아이콘을 누르면 사이드바가 슬림 모드로 전환되어 메인 화면을 더 넓게 쓸 수 있습니다.
- **✨NEW 거래처명 통합 검색**: 특정 프로젝트를 헤맬 필요 없이, 메인 화면 상단의 '거래처명 검색' 창에 업체명을 입력해보세요. 내가 담당하는 여러 프로젝트에 흩어져 있는 해당 거래처의 **모든 발주서가 한 번에 모여서** 직관적으로 조회됩니다!

## Step 3. 대시보드 요약 카드로 '오늘 할 일' 파악
- **상단 요약 카드**: 화면 최상단 고정 영역의 `미입고 지연 품목`, `오늘 입고 예정`, `이번 주 출고 예정` 수치를 확인하여 긴급한 발주서를 빠르게 선별하세요.
- **컨텍스츄얼 진척도 카드**: 좌측 목록에서 프로젝트를 선택하면, 해당 프로젝트 전용 **[입고 진행률]**과 **[출고 진행률]** 카드가 메인 상단에 나타납니다.
- **사이드바 진행률**: 사이드바의 각 항목 옆에도 **입고(Blue) / 출고(Green)** 듀얼 수치가 표시되어 목록 탐색 중에도 실시간 현황 파악이 가능합니다.

## Step 4. 🚀 입고 수량은 기본 세팅! 다를 때만 깎으세요 (Inline Edit)
- **입고 수량 Default 설정**: **[입고/전체] 칸은 발주 시점의 100% 매입 수량으로 이미 채워져 있습니다.** 주문한 대로 물건이 완벽하게 다 왔다면 타자 칠 필요 없이 다음 칸으로 이동하세요.
- **✨과입고(Over-delivery) 시각화**: 만약 계약된 수량보다 더 많은 물량이 들어온 경우, 숫자를 올리면 해당 칸이 **Indigo(남색) 컬러**로 변하며 'OVER' 배지가 나타납니다. 이는 시스템이 과입고 정책을 정상적으로 인지하고 있음을 뜻합니다.
- **일괄 입력 지원**: 발주서(PO) 단위 행의 **[일괄입력]** 버튼을 통해 하위 전 품목의 날짜를 한 번에 맞출 수 있습니다.
- **비고 및 텍스트**: 긴 비고 내용은 말줄임표 처리되며, 마우스 오버 시 툴팁이 나타납니다. 클릭 즉시 편집 모드로 전환됩니다.
- **배송비 입력**: (현재 버전 시뮬레이션에서는 제외되었으며, 추후 정산 모듈과 연동 예정입니다)

## Step 5. 팝오버 없이 직관적으로 바로 끝나는 출고 배정 
- **현장 출고(Outbound) 할당 (프로젝트 뷰 전용)**: 확보된 물자를 현장으로 보낼 때 사용하며, `출고실행` 칸에 수량을 입력합니다.
- **안전 장치**: 입고된 수량을 초과하여 출고할 수 없도록 시스템이 실시간으로 차단합니다.
- **협업 모드 (이영희 담당자)**: '연관담당자: 이영희' 역할로 접속 시, 본인이 담당하지 않는 품목은 **사선 무늬와 잠금(Locked) 상태**로 표시되어 실수를 방지합니다.

## Step 6. 버튼 누를 필요 없는 '실시간 자동 저장 (Auto-Save)'
- **Auto-Save**: 그리드에 수량이나 비고를 수정하고 포커스를 옮기는 즉시, 화면 하단에 **[입력 내용이 자동 저장되었습니다]** 알림이 나타납니다. 별도의 저장 버튼을 찾을 필요가 없습니다.
- **개발자 가이드 모드**: 화면 상단의 `DEV GUIDE` 버튼을 켜면, 각 기능의 상세 기획 의도가 담긴 **Sticky Memo**가 나타납니다. 이 메모는 시뮬레이션 상에서 즉시 수정하여 팀원들과 공유할 수 있습니다.

> 🎉 **축하합니다!** 이제 엑셀 파일이 없어도 완벽한 추적과 보고가 가능합니다. 입력 중 실수로 숫자를 줄여도 시스템이 알아서 '조정(ADJUSTMENT)' 내역을 남겨주니 안심하고 기입하세요.

> 💡 **Tip (엑셀 다운로드 활용법):** 상단 측면의 `[엑셀 일괄 다운로드]` 버튼을 누르시면, 내가 담당하는 모든 프로젝트의 전체 내역이 다운로드 됩니다. **첫 번째 시트에는 모든 데이터가 통합**되어 있고, **나머지 시트들은 프로젝트별로 나뉘어져** 있어 원하는 형태로 한 번에 가공하기 편리합니다. 통합 시트 맨 첫 열에 `[프로젝트명]`이 포함되어 있으므로, 엑셀에서 필터나 피벗 테이블을 활용해 보세요!
