# 12. 구매담당자 수급 터미널 PRD 및 업무정책서

## 1. 문서 개요
- **문서명**: 구매담당자 입출고 수기 터미널 (Buyer Dashboard) PRD
- **대상 화면**: `SCR-PUR-001`
- **작성 목적**: 기존 엑셀 기반의 수급 관리 업무를 전산화(시스템화)하며, 데이터 변경 시 백엔드 원장과 동기화되도록 하는 터미널 구축.

## 2. 배경 및 문제점 (As-Is)
- 구매/수급 담당자는 각자 엑셀 파일로 발주 내역, 입고 및 출고 상태를 관리하고 있어 부서간(물류, 재무) 데이터 공유가 실시간으로 이루어지지 않음.
- 하나의 담당자가 약 20여 개의 프로젝트를 동시 진행하므로, 화면 진입 시 자신이 맡은 프로젝트들을 한눈에 비교하고 선택할 뷰가 부재함.
- 수급 내역 중 1:N 이나 N:M 매핑(하나의 PO가 여러 프로젝트로 쪼개지는 등)을 수동 관리하다 보니 데이터 정합성 오류 빈번 발생.

## 3. 핵심 목표 및 정책 (To-Be)
1. **유연한 수급 현황 모니터링 및 역할 관리 (Multi-Role Support)**
   - **GNB 네비게이션**: 8개 핵심 메뉴를 통한 빠른 도메인 이동 지원.
   - **역할 전환 (Role Switcher)**: 구매오너(김철수)와 연관담당자(이영희) 관점을 전환하여 담당 품목별 권한 관리 시뮬레이션. (연관담당자는 본인 외 품목 수정 불가)
   - **개발자 가이드 모드**: 화면 내 Sticky Memo를 통해 기획 의도 실시간 확인 및 수정 가능.
   - **LNB 사이드바**: 프로젝트/발주서 뷰 토글 및 사이드바 최소화 기능 지원.
   - **글로벌 검색**: GNB 영역의 거래처명 검색창으로 전 프로젝트 대상 통합 조회.
2. **엑셀과 동일한 수기 입력 및 실시간 자동 저장 (Auto-Save)**
   - 메인 그리드 상에서 직접 수량, 입출고 일자 등을 기입할 수 있음. (배송비는 시뮬레이션 고도화 단계에서 연동 예정)
   - **Batch Date Input**: 발주서(PO) 단위 행마다 [일괄입력] 버튼을 노출하여, 하위 전 품목 단위로 날짜 일괄 세팅 지원.
   - **Auto-Save 메커니즘**: 사용자가 데이터 값을 변경할 때마다 하단 토스트 팝업과 함께 실시간 원장 반영 트랜잭션 실행.
3. **입고 기본값(Default) 자동 할당**
   - 사용자의 입력 피로를 줄이기 위해, 입고 수량은 기본적으로 '발주/매입 수량'의 100%로 채워져 있음.
   - 부족하거나 불량인 경우에만 숫자를 깎음 (수정 시 하이라이팅).
4. **엄격한 데이터 무결성 및 정책 준수**
   - **출고 배정 통제**: 출고 수량은 확정된 '입고 수량'을 초과할 수 없도록 통제.
   - **과입고(Over-delivery) 정책**: 발주량 초과 입고 시 시각적 알림(Indigo 하이라이트)을 통해 담당자 주의 환기 및 정책적 허용 여부 식별.
   - **조정(Adjustment) 기록**: 수량 축소 시 삭제 대신 Adjust 기록을 남겨 추적성 보장.
5. **데이터 가공 친화적 내보내기 (Export)**
   - 엑셀 일괄 다운로드 시 첫 번째 시트에는 전체 데이터를 병합하여 제공하고, 나머지 각 시트에는 프로젝트별로 분리하여 제공.
   - 통합 시트 첫 열에 [프로젝트 정보]를 삽입하여, 실무자의 피벗 테이블 및 2차 데이터 가공 작업을 적극 지원.

## 4. 사용자 여정 (User Flow)
1. **진입**: 시스템 메뉴에서 [입출고 수기 터미널] 클릭.
2. **탐색 (좌측 사이드바)**: 좌측 리스트에서 진척률이 부족하거나 관리가 필요한 프로젝트 선택 (검색 지원).
3. **확인 (단순 조회)**: 화면 최상단 3개의 요약 카드(미입고 지연 품목 등)를 통해 '오늘 처리해야 할 항목'을 확인하고, 리스트 선택 시 나타나는 별도의 진행률 카드로 진척도를 파악합니다.
4. **기입 (Inline Edit)**: 중앙 그리드에서 입고 품목 확인 후, 수량 수정 또는 입출고 일자 등을 기입. (과입고 시 Indigo 하이라이트 확인)
5. **저장 (Auto-Save)**: 포커스 해제 시 자동 저장 토스트 표시 및 즉각 시스템 기록.
6. **역할 전환 확인**: 타 담당자 품목 조회 시 Locked 상태 확인 및 업무 협업 수행.

## 5. 정책 제약 사항
- 저장된 데이터는 재무 단위의 [정산] 마감이 완료되면 수기 터미널에서 수정할 수 없으며 (Read-Only 전환), 권한이 있는 관리자를 통한 수동 정정(Adjustment) 프로세스만 허용됨.
- 배송비의 경우 발주 단위 혹은 부품 단위로 입력 시, 연관된 프로젝트/공고의 비용 항목으로 안분(Proration)되어 전표가 생성됨.
